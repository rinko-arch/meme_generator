# Générateur de Mèmes

Application web développée en Python permettant de créer des mèmes personnalisés.

## 🔗 Accès en ligne
[Cliquer ici pour accéder à l'application](https://memegenerator-ywhdxkudpbbpuwhcdudpnc.streamlit.app/)

## Fonctionnalités
- Upload d'une image depuis son appareil
- Ajout de deux textes personnalisables (taille, couleur, position)
- Aperçu en temps réel des modifications
- Téléchargement du mème créé
- Galerie des mèmes sauvegardés
- Partage sur Twitter et Facebook

## Technologies utilisées
- Python
- Streamlit — interface web interactive
- Pillow — manipulation d'images

## Lancer le projet en local
1. Installer les dépendances
pip install streamlit pillow

2. Lancer l'application
streamlit run app.py
